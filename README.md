
#### ISOnline Chat

Это **псевдочат** для настольной ролевой игры [IsOnline](https://rpgbook.ru/isonline). 

Он имитирует внутриигровой чат MMO с отсылками к онлайн играм и НРИ сообществу.

Предназначен для того, чтобы игроки
- больше погружались в атмосферу во время сессии, видя “живую” ленту событий и разговоров 
- получать сообщения с сюжетными завязками без участия Гейм-мастера напрямую

Сообщения появляются автоматически по времени и синхронизированы у всех игроков через через UTC-время.

Если хотите предложить свои сообщения свяжитесь с [автором](https://yevwke.ru/)




##### Как изменить под себя
- Сделайте форк репозитория
- В файлах `chatcommon.json` и `chatrare.json` добавьте сообщения
    - В`chatcommon.json` находятся сообщения спама, объявлений etc которые будут часто повторятся, создавая информационны шум
    - В`chatrare.json` находятся сообщения более редкие сообщения в которых можно 
- В начале файла `script.js` настройте интервалы сообщений (если необходимо) 
- Настройте github pages для получения ссылки на ваш чат
