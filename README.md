
### ISOnline Chat

Это [псевдочат](https://yevwke.github.io/isonline_chat/) для настольной ролевой игры [IsOnline](https://rpgbook.ru/isonline). 

Он имитирует внутриигровой чат MMO с отсылками к онлайн играм и НРИ сообществу.

#### Назначение
Предназначен для того, чтобы игроки:
- больше погружались в атмосферу во время сессии, видя “живую” ленту событий и разговоров 
- получали сообщения с сюжетными завязками без участия Гейм-мастера напрямую

#### Принцип работы
Сообщения появляются автоматически по времени и синхронизируются у всех игроков через UTC-время.

Отображение основано на заранее заданных списках сообщений.  
На данный момент список сообщений небольшой и подойдет максимум для одной игровой сессии. 
Если хотите предложить свои сообщения — свяжитесь с [автором](https://yevwke.ru/) или адаптируйте проект под себя.

---




#### Как изменить под себя
- Сделайте форк репозитория
- В файлах `chatcommon.json` и `chatrare.json` добавьте или измените сообщения
    - В`chatcommon.json` находятся сообщения спама, объявлений etc которые будут часто повторятся, создавая информационный шум
    - В`chatrare.json` находятся более редкие сообщения общения и сюжетных зацепок(в идеале надо обновлять этот список под каждую сессию)
- В начале файла `script.js` измените интервалы сообщений (если необходимо) 
- Настройте github pages для получения ссылки на ваш чат
